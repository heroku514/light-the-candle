# Findings - Light the Candle

## 2026-10-03

- Pipeline apps through Hold the Lace are Waiting for Review. No version state contained REJECT.
- Competing candle apps, including Candles: Candle Light and Candle Simulation, draw a glowing flame and often listen for a breath. Light the Candle does not draw a flame and does not use a microphone. The match works once, and a spent match cannot light the candle again.
- Shipped apps already cover ordered buttons, a two-seat blanket, and a bow that needs both hands. This rule is a one-use match.
